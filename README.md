# Desafio 1 - Api Lista de Compras

## Como rodar

1) Baixe o repositório ou clone através do comando

```git clone https://github.com/Kohlrausch16/desafio-panvel-questao-1```

2) Para iniciar aplicação, utilize o comando abaixo na pasta raiz do projeto:

```./mvnw spring-boot:run```

2) Após iniciar aplicação esta pode ser acessada através de ```http://127.0.0.1:8080/produtos```.

## Banco de dados

Para o desafio, foi utilizado o banco de dados em memória H2 Databse, o qual pode ser consultado através de ```http://127.0.0.1:8080/h2-console```
